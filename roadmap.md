# KAIROS APP roadmap

## Done (phase 1)
- Flat white, soft-green and red design system, app shell, desktop + mobile navigation
- Database: profiles, roles, ministries + members, follows, posts, likes, comments,
  prayer requests + intercessions, events, live stream listings, gifts, Bible verses,
  bookmarks, notifications — all with RLS and grants
- Email/password + Google sign-in, auto profile creation
- Home feed, create post/prayer, prayer wall, ministries (create/follow), discover,
  events, Bible search + bookmarks, giving records, profile, notifications

## Not built yet

- Large-audience streaming, cloud replays and server-quality transcription
- Sermon transcription and AI summaries
- AI Bible verse detection and related-Scripture suggestions
- Full Bible import (only a starter verse set is loaded)
- Notification generation, analytics dashboards, admin console
- Live recording downloadable on the host device after the live ends (not uploaded to the cloud)
- Scripture lookup by reference (any verse) + word search in starter set; one-tap verse on screen; eight backgrounds
